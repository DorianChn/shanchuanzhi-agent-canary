顶部导航可进入事前审查、Agent 接入和真实实验。模型连接、Provider/模型选择和加载错误为真实后端结果。

步骤：连接已有 Ollama → BALANCED → 正常读取 → 开启本地事前审查 → 请求虚拟写入 → 查看实际模型结构化结果 → 独立操作者批准一次或拒绝。模型 benign 仍不能执行待批操作。operatorCode 由后端环境指定，不通过 GET 返回，不写 localStorage；默认没有口令时审批不可用。

敏感来源演示：关闭 AI（确定性防护保持）、请求虚拟来源并由操作者批准、尝试传出不透明字符串 → 来源历史保守拒绝；导出含时间线、决策、来源哈希和模型结果的 JSON。

Agent 安装仅写临时项目；按钮可预览/安装/恢复，并实际验证 SDK stdio 握手与隔离。元数据检测不等于应用安装。真实实验按钮运行固定本地 A/B/C/D/E 任务，报告是保存结果，非动画假模型。

只保护注册到 Router 的宿主 callback。MCP 诱饵安装不等于全局保护；绕过 Guard、已开始的外部操作、模型内部状态 OUT_OF_SCOPE。AI 不能批准、重置 Guard 或改权限。realpath 仍有 TOCTOU 窗口；自定义网络 callback 需使用 DNS 固定与禁止重定向的安全 transport。来源提示不等于完整动态污点分析。
