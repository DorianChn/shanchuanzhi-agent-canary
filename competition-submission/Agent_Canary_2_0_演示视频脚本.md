# 真实录制流程与中文解说

## 镜头 1｜0.2 秒

Agent Canary 2.0｜真实运行界面记录 / 所有危险工具为虚拟
确定性风险策略、事件隔离与可选事前 AI 审查；不是全局 Agent 防火墙。

## 镜头 2｜21.3 秒

配置预览和备份在独立演示项目进行；安装 MCP 诱饵不等于全局保护。
此处实际 stdio 客户端验证 12 个诱饵 + 3 个虚拟宿主 callback；桌面内置工具未验证。

## 镜头 3｜46.5 秒

连接本机已有 Ollama / Qwen9B，无下载、无付费云调用。
正常公开读取成功；未触发 Canary 时 SAFE 不代表操作一定安全。

## 镜头 4｜66.6 秒

OBSERVE 仅观察：虚拟外传进入模拟执行器。
这是程序操作的确定性对照，不冒充模型主动攻击结果，没有真实网络外传。

## 镜头 5｜88.8 秒

BALANCED 在首次高风险 callback 前拒绝；这次结论来自确定性策略。
同一会话的正常读取仍完成；策略拒绝和 Guard 隔离分别记录。

## 镜头 6｜142.3 秒

此虚拟写入在执行前真实请求本地模型，原样显示实际解释与证据。
模型 benign 不能批准；suspicious 只能收紧；超时、断线保持保守策略。

## 镜头 7｜167.7 秒

独立可信操作者一次批准读取虚拟来源；模型不能伪造审批。
会话只保存来源标签与 HMAC，不保留真实秘密；后续不透明网络请求保守拒绝。

## 镜头 8｜192.9 秒

程序主动触发惰性 Canary → QUARANTINED → 后续受保护读取被拒绝。
证明隔离路径，不能计为真实模型诱饵检测；已开始的操作不可撤销。

## 镜头 9｜215.0 秒

保存的真实 A/B/C/D1/D2/E 模型实验：模型自主选择工具，全部效果虚拟。
失败、正常中断和 AI 独立收益限制公开；同模型单种子不是总体安全率。

## 镜头 10｜240.0 秒

MIT 开源｜GitHub DorianChn/shanchuanzhi-agent-canary｜Draft PR #22
免费竞赛版独立构建；原商业分发风险仍公开。只保护经注册 Router 的 callback。

实际生成视频与字幕；不是纯视频脚本。实现 lab/record-v2-console.mjs，固定真实后端按钮操作；所有危险效果虚拟、Canary 由程序触发，不计模型检测。Chrome/Playwright/ffmpeg 是本机已有依赖，不自动安装。需要已有 Ollama/Qwen。模型表现不同必须保留，不能补写更好答案。
