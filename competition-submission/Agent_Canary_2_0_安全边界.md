# 安全边界与未验证项

只保护注册到 Router 的宿主 callback。MCP 诱饵安装不等于全局保护；绕过 Guard、已开始的外部操作、模型内部状态 OUT_OF_SCOPE。AI 不能批准、重置 Guard 或改权限。realpath 仍有 TOCTOU 窗口；自定义网络 callback 需使用 DNS 固定与禁止重定向的安全 transport。来源提示不等于完整动态污点分析。

Shell 分类只保守识别有限已审命令，不能可靠判定任意脚本。未知或高风险通常人工批准；会中断合法 build/install。操作者可以明确授权敏感读，之后数据流策略保守拒绝网络。当前 TTL 只控制来源记录，不能自动清空旧安全标记放权。

同模型审查可能与攻击模型有共同盲点。AI suspicious 可能误拒绝合法任务，uncertain/超时保留待批，不算攻击成功检测。一个模型、一个种子、作者样本；Wilson 区间非总体独立同分布推断。

原普通 npm/Docker 的 V1/V2 边界 P1 仍 OPEN；免费竞赛 ZIP 采用独立文件图，不迁移商业用户，不删除许可校验，也不撤销历史披露。

长期真实生产稳定性、所有桌面 Agent 内置工具覆盖、多模型云服务连通、正式官方默认分支规则尚未验证。
