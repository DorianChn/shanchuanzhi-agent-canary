# 独立复现结果签收模板

请由真实操作者填写，不由项目作者或 AI 代签。

- 操作者（可公开化名，真实身份自行留存）：
- 是否项目作者 / 是否参与策略调试：
- 独立设备与环境：
- OS / Node / Python / Ollama 版本：
- 下载时间、公开 URL、实际 ZIP SHA256：
- 冻结运行时 SHA：99660b36db9d5b1121eea6fe06b026c5f1e36bcf
- 使用的脚本 SHA256：
- 完整命令与开始/结束时间：
- 正常任务真实效果：
- 无保护与完整系统配对：
- 实際拒绝与副作用观察者、窗口和目标：
- 全部失败 / 超时 / 未尝试：
- 原始结果 JSON/CSV/JSONL 保存位置与 SHA256：
- 与已发表结果差异：
- 是否只运行离线 DEMO（不能充当真实 LLM E4）：
- 允许公开的范围与联系方式：
- 操作者签收 / 日期：

独立复现只对实际运行声明及范围考虑 E4，不能授予全产品认证。
