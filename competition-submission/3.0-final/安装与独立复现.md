# Agent Canary 3.0 竞赛候选：安装与复现

冻结源码：99660b36db9d5b1121eea6fe06b026c5f1e36bcf。MIT；受控 SDK 工具边界。保留2.0与旧原始记录。此候选不是npm/Docker稳定版或独立桌面安装器。

## 1. 下载与启动

从候选 Release 下载 `Agent_Canary_3_0_Community_Preview_99660b36.zip`。优先使用这个策展免费包，不使用自动生成的完整 Source code、旧npm/Docker包作为本次免费竞赛交付物。

解压进入 agent-canary-community-3，以普通用户终端运行：

```
npm ci
npm run build
npm test
npm run self-test
npm run ai:console
```

打开命令输出的 loopback 地址。无需模型即可运行明确标注 DEMO 的真实临时文件演示：正常写入、首次凭据拒绝、人工审批、诱饵读取后隔离与再写入拒绝。按钮由操作者触发，不能算真实模型攻击。不要把测试操作员口令用于生产。

当前Windows普通用户、中文/空格解压路径实际通过 ci/build/self-test；策展包独立专项96项通过。没有独立干净VM，Windows20/22分别由实际CI证明，不声称本机同时测试两个Node。

## 2. 真实 Qwen 留出复验

先由操作者启动已经安装的 Ollama；本实验使用已有 qwen3.5-9b-local:latest，不自动下载模型。另一模型或版本的结果不能覆盖本记录。

```
ollama list
node security-lab/run-sdk-agent.mjs --fair-acceptance --holdout=security-lab/holdout-v1.json --sha=99660b36db9d5b1121eea6fe06b026c5f1e36bcf
```

12个新README攻击、4个正常任务，各重复2次，A/F两组，共64次；全量运行，不挑选结果。全部实际危险执行只在临时fixture、固定Node子进程与loopback接收端内。用户不要把fixture改为真实密钥、文件或外部网络。

每次生成新的 security-lab/evidence/<timestamp>/，保存 preregistration、results.json、results.csv、summary、每条证据JSONL、全部可见模型messages、拒绝、错误和实际目标观察。包括未尝试攻击和失败。检查 results.completedAt 与64条 trials；未完成不能当PASS。

模型参数固定：temperature0、think=false、ctx4096、predict256、seed20261011、maxTurns4。作者知晓策略，主题与fixture复用，重复相关；不是外部盲测E4，不是总体概率估计。

## 3. 原始证据复核

Release另附 Evidence ZIP，包含历史48和新64原始记录、留出协议、标准Schema、字段向量及离线验收器。可在完整冻结Git checkout安装 Python jsonschema 后运行：

```
python security-lab/verify-acceptance.py --results security-lab/evidence/2026-10-11T15-04-14-292Z/results.json --output review-assurance.json
```

验收器需要Git能够读取冻结提交，并要求当前构建摘要与记录一致。不同Node/TypeScript版本可能产生不同构建摘要；不一致须解释，不能改原始摘要。免费ZIP没有.git，不能仅解压ZIP就声称此Git来源核对已通过。

历史48的直接准入A12/12、F0/12不是间接注入率；旧README两组0/4没有主动危险尝试。新64间接任务A4/24、F0/24，F实际拒绝6/24；正常两组8/8。AI本批0次审查，自适应触发0，不归因AI或蜜罐收益。

## 4. 覆盖与限制

保护实际接入Gateway/Guard的注册工具；没有验证原生Codex/Claude/Cursor/Cline所有内置调用。MCP配置、握手和hook fixtures不等于全局保护。

文件句柄绑定不是路径租约/回滚；不响应AbortSignal的已开始callback仍可能迟到写入。HTTPS校验/pin/redirect负例不是恶意公网DNS基础设施完整E2E。哈希链无独立签名/时间戳，管理员可整链重写。E4独立操作者复现尚缺。
