# Support and feedback

Use the channel that matches the request. Public issues and discussions are visible to everyone; do not post secrets, private configuration, customer data, or exploit details.

## Setup and usage questions

Ask general setup or usage questions in [GitHub Discussions](https://github.com/DorianChn/shanchuanzhi-agent-canary/discussions). Include the exact release or commit, OS, Node.js version, host, and the step where you got stuck. Use a scratch project and remove private paths before posting.

## Reproducible bugs

Use the [bug report issue form](https://github.com/DorianChn/shanchuanzhi-agent-canary/issues/new/choose). Give the expected and observed behavior and a minimal reproduction with synthetic data. A `DENY` label by itself does not show that a side effect was prevented; include callback counts or before/after hashes when relevant.

## Product feedback

Use the [product feedback issue form](https://github.com/DorianChn/shanchuanzhi-agent-canary/issues/new/choose) or a Discussion. Feedback is public if submitted there. Use a pseudonym or omit identity, and ask before quoting anyone outside the original report.

## Security vulnerabilities

Report exploitable vulnerabilities through a [private GitHub Security Advisory](https://github.com/DorianChn/shanchuanzhi-agent-canary/security/advisories/new). Do not publish exploit steps or sensitive logs in an issue or Discussion. See [SECURITY.md](SECURITY.md) for scope and disclosure guidance.

## Response expectations

This is a community open-source project. Reports are reviewed as maintainer capacity allows; no response-time SLA or bug-bounty program is published. A report or discussion does not imply that a fix, feature, or release date is committed.
