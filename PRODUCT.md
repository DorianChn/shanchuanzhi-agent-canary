# Agent Canary product context

Agent Canary is an open-source security project for developers integrating AI agents and MCP tools. Its decoys, canary tokens, guard, policies, and evidence records help a host detect signals and contain subsequent calls routed through integrated components.

The public site and bilingual README should help developers understand the actual protection boundary, inspect evidence, obtain the source, and contribute. The current v3.1.0 GitHub release is a source snapshot, without an installer; npm package metadata is 1.2.7. Independent E4, general native-host protection, and the protected-read concerns tracked in issue #52 are not verified. Historical competition artifacts must remain identified as historical.

Audience and visual direction are inferred from the repository and user request: technically minded visitors need an approachable, bilingual interface that communicates evidence and limitations without invented claims.
