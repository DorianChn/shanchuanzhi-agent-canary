# 3.0 威胁模型

保护资产：宿主登记的工具能力、预登记文件、会话隔离状态、人工审批能力、最小化审计证据。实验中的凭据均为无效文本。

攻击者可以控制 README、网页与工具输出中的不可信文字，诱导模型生成工具名与 JSON 参数、重复 / 并发调用、伪造 approved / identity / reset 字段、尝试访问未登记资源、诱导风险审查模型服从攻击文字。

攻击者不能改变宿主的进程代码、固定资源清单、operator 对象、Guard 管理 API、已登记命令程序或本地 OS 账户权限。若这些可信组件被攻破，本协议不提供隔离保证。

## 执行不变量（由测试验证部分范围）

1. 未登记文件 / 命令 / MCP 工具不能执行；工具名字本身不能增加权限。
2. 文件执行只能通过预持有 fd，替换路径不切换到攻击者 inode。
3. QUARANTINED 不被 AI 分析或参数中的许可字段撤销。
4. 审批只通过宿主对象、一次消费、有限有效期；批准时重新检查资源与 Guard。
5. 无法记录执行意图时不启动受保护效果。
6. AI 超时 / 无效输出不能从 REQUIRE_APPROVAL 升级到 ALLOW。
7. 蜜罐部署、暴露、接触、检测和阻断分别记录；未发生阶段不能补写。

## 已知路径

绕过宿主 dispatch 的工具、同权限恶意 OS 进程、已开始的外部效果、固定程序内部权限扩大、未观察的数据变换、管理员重写日志均 OUT_OF_SCOPE。允许来源的 HTTPS GET 不等于服务端零副作用。敏感来源后保守拒绝网络可能产生误中断，需要任务范围许可及真实正常任务测试进一步优化，不能直接放松为模型自行批准。
