# 本地控制台设计边界

这是现有实验看板的扩展，沿用深色 navy 背景 #0b1020、panel #151d32、mint 主动作 #55d6be、amber 建议和红色错误。中文系统字体、15 px 正文/1.65 行距，按钮 8 px、面板 12 px 圆角，面板间 28 px；850 px 以下单列。没有外部字体、图标或资产请求。

使用顺序：连接模型 → 选择真实事件或明确标记的虚拟输入 → 阅读脱敏预览 → 云端确认 → 分析建议 → 下载报告。原始上下文、AI 结论与确定性隔离结果分别显示，不把模型输出称为事实。空、加载、取消、断线与格式错误有明确状态。控制台没有重置 Guard 的按钮。

UI 只代表本地当前进程和 JSONL 最近 100 条记录；不显示虚构全局安全分数、未记录的成功调用数或费用。实验中心复用仓库 lab，不提供危险 Shell/真实 HTTP callback。记录与结果逐项保留，不替换失败数据。
