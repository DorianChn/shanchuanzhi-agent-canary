安全，从看清开始。

Agent 可以调用工具，也可能遇到不可信的指令。Agent Canary 把可观察的信号和受守卫的执行连在一起。

它不是覆盖所有桌面工具的系统级沙箱。效果取决于宿主如何接入、策略如何配置，以及实际执行路径。

从信号到行动

宿主需要主动接入受保护的路径；以下步骤描述项目中的机制，而非对所有 Agent 的覆盖承诺。

发现信号

诱饵工具和已登记令牌提供可检查的异常线索。触发后仍需结合上下文判断。

限制后续调用

Guard 和策略约束接入路径中的调用；会话隔离不能撤销已经开始的外部操作。

留下证据

记录决策与执行状态，保留测试失败和未验证事项，供复现和审查。

边界不是小字。

了解哪些路径接入、哪些效果已经核验，是使用安全工具的第一步。
