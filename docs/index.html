一套免费工具，覆盖完整流程

发现信号、执行隔离、查看证据，都可以本地复现和核查。

无害 MCP 诱饵

12 个合成高风险工具。处理器不会执行命令、读取秘密或连接业务服务。

金丝雀令牌

在蜜罐中植入随机无权限值，并扫描文件、标准输入或监控目录中的精确匹配。

受守卫操作隔离

SDK 会话熔断器会拒绝后续经过同一会话 guard 的真实工具调用。

模型注入评测

用版本化的 20 条提示载荷评测本地 Ollama 或云 API 模型；提供方错误按未通过处理。

离线攻击链面板

把本地脱敏事件日志生成单文件 HTML 时间线，无需第三方脚本。

SIEM 导出

导出 CEF、JSONL 或 CSV；CSV 会中和可能被表格执行的公式字段。

几分钟开始使用

需要 Node.js 20+；无需账号或激活。

git clone https://github.com/DorianChn/shanchuanzhi-agent-canary
cd shanchuanzhi-agent-canary
npm ci && npm run build && npm link
agent-canary init
agent-canary self-test
agent-canary tokens plant .env.canary --label my-project
agent-canary install claude

本地模型评测：先运行 ollama pull qwen3，再运行 agent-canary eval --provider ollama --model qwen3。本地推理使用自己的硬件；云模型提供方可能收取 API 费用。

明确能力边界

隔离只覆盖经过集成 SDK guard/router 的工具调用。若首次真实操作绕过这条路径，工具无法阻断；项目也不代理任意 MCP 服务。
评测分数只反映指定模型在这 20 条载荷上的当次表现，不是安全认证，也不证明模型能抵御所有攻击。
诱饵调用或令牌出现在埋放文件外是需要核查的信号；它本身不证明真实数据已被窃取。
事件默认保存在本机；Webhook 为可选功能，只向你配置的地址发送脱敏事件。
