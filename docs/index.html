MCP 诱饵与 Canary Token

12 个不执行所模拟操作的诱饵工具，加上已登记令牌的精确匹配，产生可审计信号。误调用也可能触发，仍需结合上下文核查。

确定性策略与会话隔离

Guard 同步执行 SAFE → TRIPPED → QUARANTINED；已隔离会话的后续受守卫危险调用被拒绝。可信宿主可增加参数策略与有限敏感来源追踪。

从独立免费包开始

下载 ZIP 并解压，在解压目录运行以下命令。无需模型也能自检并运行控制台；使用 AI 时再连接已有本地模型或明确授权的接口。

npm ci
npm run build
npm test
npm run ai:console

控制台仅在本机 loopback 启动，使用命令输出的网址。AI 事前审查默认关闭。独立竞赛包不是原商业 CLI，MCP 启动命令是 node dist/competition.js serve --stdio。

使用前了解保护边界

  • 安装 MCP 诱饵不等于全局 Agent 防护。只有宿主接入 Guard / Router 的调用受其隔离策略保护；未接入的原生工具和其他 MCP 服务在范围外。
  • 未产生 Canary 信号的首次危险调用不由原始 Guard 自动识别；可选风险策略能检查宿主声明的参数边界，但不是完整命令语义验证器。
  • AI 只辅助分析，不能自行批准、重置 Guard 或解除隔离。不能撤销已经开始的外部操作，实际桌面 Agent 的全链路保护尚未验证。
  • 请选择本页的独立免费 ZIP。普通 npm/Docker 的 V1/V2 分发边界风险仍未关闭，本次不发布这些渠道，不迁移商业用户。
