3.0 竞赛版包含什么

本发行面向本次竞赛提交与 Community 体验，所有可下载文件和验收记录集中在 GitHub Release。

Windows 安装器

适用于 Windows 11 x64，内置 Node.js 22.23.1；当前用户图形安装、控制按钮、导出、重启恢复和卸载流程已验证。安装器未签名。

CLI / SDK 源码包

提供 Community CLI/SDK 源码与构建分发，可查看类型、安装说明和 SHA-256 清单。Ubuntu 流程需要 Node.js 20/22、Python 3，安装依赖时需要网络。

验收与复现材料

发行附件包含验收证据、公开验收回执、Windows 构建记录、安装说明和摘要文件。请按 SHA256SUMS 校验下载。

验证结果与适用边界

公开验收覆盖候选版 4 的 Community 包及其指定提交。下列数据描述这次验证范围，不代表所有宿主、模型或环境都具备相同效果。

已公开的验证摘要；详细步骤、失败项及分母见 Release 附件和验收回执。

请先了解这些限制

  • 不承诺完整消除 TOCTOU，也不提供全局原生宿主防护；非协作 callback 可能产生延迟副作用。
  • 干净 Windows 虚拟机验证仍为 BLOCKED，E4 仍为 NOT_VERIFIED；独立 AI/自适应增益尚未测得。
  • 安装器未签名。当前图形验证是同一用户环境验证，不等于干净机器认证。
  • 仓库根 npm 清单仍是 1.2.7。本发行只发布 3.0 Community 竞赛包，不代表 npm、GitHub Packages、Docker 或旧 V2 商业渠道已发布 3.0。
