3.0 主线提供什么

主线包含可运行的 CLI、MCP 服务、SDK、离线自检和本地策略控制台。发行包不接管未由宿主注册的工具或系统能力。

CLI 与 MCP

通过 agent-canary 命令运行自检、守卫网关与 stdio MCP 服务。Node.js 20 或更新版本。

SDK 执行网关

宿主显式登记需要守卫的执行回调；拒绝、审批、取消和证据状态可在限定路径中检查。

测试与边界

发布工作流运行构建、测试、离线验收、类型消费与安装包冒烟检查。公开页面同时列出既有验收范围与未验证项。

获取 3.0.0

Agent Canary 3.0.0 已发布到 GitHub Release、GitHub Packages 和 GHCR。npm 版本为 3.0.0；公开容器镜像提供 3.0.0 与 latest 标签。

GitHub Packages · npm

使用 GitHub Classic Personal Access Token 并授予 read:packages 权限。

npm config set @dorianchn:registry https://npm.pkg.github.com
npm login --scope=@dorianchn --auth-type=legacy --registry=https://npm.pkg.github.com
npm install --global @dorianchn/agent-canary@3.0.0

GitHub Container Registry

拉取 3.0.0 容器镜像并运行 CLI。

docker pull ghcr.io/dorianchn/shanchuanzhi-agent-canary:3.0.0
docker run --rm ghcr.io/dorianchn/shanchuanzhi-agent-canary:3.0.0 --help
