# Legacy sponsor gateway — archived

This folder contains the former experimental payment and license gateway. Agent Canary 2.x no longer sells feature access and does not require a license server, subscription, activation handle or payment.

**Do not deploy this gateway to accept new payments or issue licenses.** It is not required by the CLI, SDK, evaluation suite or public package. All Agent Canary features are available under the repository's MIT license.

The source and its local demo smoke check are retained for historical reference. Do not commit environment files, private keys, QR codes, order records, subscriber data or activation records. The CI smoke mode uses local demo data only and does not contact payment providers.
